Environment Links

In the address bar type e then Space or Tab, then a link name, e.g. backoffice, backoffice prod or backoffice stag /users.

How to use Environment Links

  1. Set up your environments

    In Variables, each row is an environment and each column a variable. Give each environment its own values, e.g. ENVIRONMENT = dev for DEV. Put values every environment shares, like DOMAIN, in the Default row.

  2. Add a link

    In Links, give it a short name and a URL template that uses your variables, e.g. backoffice → backoffice.{{ENVIRONMENT}}.{{DOMAIN}}. Expand it with ▸ to check the URL for every environment, or to type a different URL for one of them.

  3. Open it from the address bar

    Type e, press Space, then the link name: backoffice. Pick an environment with ↑ ↓ and press Enter. Add environment names to narrow the list (backoffice prod) or a path to land on a page (backoffice stag /users).

  4. Or use the toolbar button

    Click the extension's icon for every link with a button per environment. Type to filter, use the arrow keys to choose, and press Enter. Can't see the icon? Click Chrome's puzzle-piece icon and pin Environment Links.

  5. Share with your team (optional)

    Commit a links file to a GitHub repository, then add it in Shared links. Everyone who adds it gets the same links, and anything you set yourself still wins.

Variables

Each row is an environment and each column a variable. A blank cell uses the value in the Default row. Use them in templates as {{NAME}}.

Links

The name is what you type after e. Expand a link to preview it, or to override the URL for one environment (e.g. production without the {{ENVIRONMENT}}. part).

Shared links

Pull links from a JSON file in a GitHub repository so your team keeps one list. The file can also set environments and variables. Anything you set yourself wins: your own links, names and values are used over the shared ones. Shared files are synced when Chrome starts, every hour, and when you click Sync now.

Create a shared file from your links
