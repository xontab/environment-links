1

Set up your environments

Each row in Variables is an environment, each column a variable. Give every environment its own values, like ENVIRONMENT = dev. Values they all share, like DOMAIN, go in the Default row.

backoffice backoffice.{{ENVIRONMENT}}.{{DOMAIN}}
backoffice.dev.example.com backoffice.staging.example.com backoffice.prod.example.com
2

Write each link once

In Links, give a link a short name and a URL template with your variables in {{double braces}}. Expand it to check the URL for every environment, or to use a different URL for one of them.

Open it from the address bar

Type e, press Space, then the link name. Choose an environment with ↑ ↓ and press Enter. Add an environment name to narrow the list (backoffice prod) or a path to land on a page (backoffice stag /users).

Share with your team (optional)

Commit a links file to a GitHub repository, then add it in Shared links. Everyone who adds it gets the same links, environments and variables, and anything you set yourself still wins.

Variables

Each row is an environment and each column a variable. A blank cell uses the value in the Default row.

Use them in templates as {{NAME}}.

Links

In the URL template, put a variable's name in double braces, like {{ENVIRONMENT}} or {{DOMAIN}}. Each environment fills in its own value from Variables, so backoffice.{{ENVIRONMENT}}.{{DOMAIN}} becomes backoffice.dev.example.com for DEV. https:// is added if you leave it out.

While you edit a link, its URL for every environment is shown below it. Type in an environment's box to use a different URL there, e.g. production without the {{ENVIRONMENT}}. part.

Shared links

Pull links from a JSON file in a GitHub repository so your team keeps one list. The file can also set environments and variables. Anything you set yourself wins: your own links, names and values are used over the shared ones. Shared links are synced when Chrome starts, every hour, and when you click Sync now.
